# Baserate

Redemption-free BTC→MUSD credit on Mezo's own Morpho Blue, with composable sMUSD savings.

> Work in progress for the Mezo Buildathon. See `docs/PLAN.md` for the plan and `docs/design/` for specs.

## Layout

- `contracts/` — Foundry project (Solidity 0.8.28)
- `apps/` — web app and keeper (coming)
- `packages/` — ABI and SDK packages (coming)
- `docs/` — plan, design specs, research
